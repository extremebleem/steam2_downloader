Files are stored as deltas: extracting version N needs every version below it too. Where a depot was reset the same version number exists twice and the chain forks — the planner follows the parent links recorded inside each blob to work out which files are actually needed.

Download blobs by depot range

A blob is a depot's metadata: the file list of one version, tens to a few hundred kilobytes depending on how many files that version had. Pulling a span of them fills in version history, per-version diffs and the global file search for every depot in the range, for a small fraction of what the dats would cost. No dat is downloaded — the estimate below is the real figure for the range you picked.

Sharing is on

This app now shares the depots you have downloaded back to the swarm, and takes part of new downloads from it.

The archive is 13 TB kept alive by a handful of people seeding it, and three HTTP mirrors paid for by one person who has asked everyone to pull less from them. Every file you share is one those servers are not asked for. Only files you already have are offered — nothing extra is downloaded to share, and your download speed is never held up by it.
